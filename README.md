# Haikuron.fi
The haikuron.fi website


# How to use
    1. clone directory
    2. cd to main
    3. run npm i
    4. to run dev: npm run dev

# Building
    1. npm run build
    2. to test build: npm run start

# Transfer to host
    1. build
    2. check if build is correct
    3. drag the content of out folder to httpdocs folder at host
    4. should work
